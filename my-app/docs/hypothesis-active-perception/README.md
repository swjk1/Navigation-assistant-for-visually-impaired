# Hypothesis-Conditioned Active Perception

Editable engineering documentation for **Hypothesis-Conditioned Active Perception and Multimodal Decision-Making for Map-Free Indoor Navigation**.

**Project deliverables**

- `technical_implementation.md` — complete technical design, modules, data interfaces, pseudocode, algorithms, training pipeline, tests and milestones.
- `system_architecture.mmd` — editable Mermaid architecture showing long-/short-term planning and information feedback.
- `decision_loop.mmd` — editable active perception decision loop.
- `example_episode.mmd` — Mermaid sequence of an illustrative room-501 search.
- `prototype_config.yaml` — baseline simulator, action and evaluation configuration.

This is a **research design**, not a completed algorithm or a validated independent mobility aid. Proposed innovations must be demonstrated against strong baselines.
